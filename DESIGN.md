# Design

## Direction

An editorial portfolio that feels like a printed studio folio: quiet paper, oversized typography, and small moments of orange signal. The work leads; the interface stays out of the way.

## Visual system

- **Palette:** warm paper `#f3f1eb`, near-black ink `#1d1d1b`, muted ink, signal orange `#e96d3c`, with project-specific blue and yellow fields.
- **Typography:** a high-contrast serif italic for emphasis against a large, tightly tracked sans-serif voice.
- **Composition:** generous negative space, asymmetric hero copy, ruled section markers, and a single-column mobile collapse.
- **Motion:** project artwork responds with a restrained grid shift on hover; all key content remains visible without motion.
- **Surfaces:** abstract project artwork is paired with the local Catalyst Forge logo; additional case-study images should only be added when provided by Devina.
